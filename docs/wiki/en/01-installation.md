# Installation

## Requirements

- **Project Zomboid Build 42.21** or later (the mod declares `versionMin=42.21`).
- **[TooltipLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3694097672)** (required): it draws the size, wear, embroidery and binder lines in item tooltips.
- **Not with [Realistic Clothes](https://steamcommunity.com/sharedfiles/filedetails/?id=3491510356)**: the two mods are declared incompatible. My Tailor Is Rich is a full rewrite of it for Build 42.21.

## Singleplayer

1. Subscribe to [My Tailor Is Rich](https://steamcommunity.com/sharedfiles/filedetails/?id=3810122988) and TooltipLib on the Steam Workshop.
2. In the mod list, enable **TooltipLib** and **My Tailor Is Rich** (`batman_MyTailorIsRich`).
3. Do **not** enable **My Tailor Is Rich - Uninstall**: it is only for removing the mod from an existing save (see [FAQ](10-faq-and-compatibility.md#removing-the-mod-from-a-save)).

The mod works in a new game and in an existing one: clothes already in the world get a size the first time it is needed.

## Dedicated or hosted server

1. Add both Workshop items to the server: `3810122988` (My Tailor Is Rich) and `3694097672` (TooltipLib).
2. Add the mod IDs `TooltipLib` and `batman_MyTailorIsRich` to the server's mod list.
3. Set the options on the **My Tailor Is Rich** page of the sandbox settings (see [Sandbox options](08-sandbox-options.md)).

> Capture à faire : the mod list with TooltipLib and My Tailor Is Rich enabled.

## Languages

English, French, German, Spanish, Portuguese (Brazil and Portugal), Russian, Simplified Chinese and Turkish.
